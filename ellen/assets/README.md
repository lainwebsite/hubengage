# Ellen Ma site – image assets

Drop the real images exported from Figma here:

- `ellen-portrait.png` – the hero portrait (transparent or dark background, about 1300px wide).
  The page loads it automatically; the silhouette placeholder disappears once the file exists.

Client logos and project dashboards are built in HTML/CSS so they animate.
To use the real logo files instead, replace the `.logo` spans in `ellen/index.html` with `<img>` tags.
